Règ konfidansyalite: anvan w kole nan AI a

Retire: adrès · telefòn · ID, viza, nimewo A (A-number), nimewo dosye · dat nesans · non, telefòn ak imèl lòt moun.

Kenbe: non ou, vil ou, imèl ou, travay ou, lekòl ou, konpetans ou.

Paj piblik: pou referans, ekri « Kontakte sou demann ». Pa mete liy sou otorizasyon pou travay.

Sove yon nouvo fichye sou GitHub

  1. Louvri repo ou a sou github.com.
  2. Add file → Create new file.
  3. Ekri non fichye a.
  4. Klike nan gwo bwat la. Ctrl+V pou kole.
  5. Commit changes, apre sa ankò Commit changes.

Chanje yon fichye: louvri li → kreyon → Ctrl+A → Ctrl+V → Commit.
Kopye li tounen: louvri li → Copy raw file (de kare).
Pa sèvi ak Downloads. Òdinatè pataje yo efase yo.

Ou bloke? Pi bon solisyon yo

404 sou lyen an: tann 2 min. Fichye a rele index.html. Repo a se Public. Settings → Pages → main → Save.

Foto a pa parèt: nan repo portfolio la? Non li se photo? Rafrechi ak Ctrl+Shift+R.

Kopye a pa fè anyen: tèks la chwazi deja. Peze Ctrl+C (Mac: Cmd+C).

Paj la sanble kase: premye liy <!DOCTYPE html>, dènye liy </html>. Li koupe? Mande fichye konplè a.

Anyen pa chanje sou entènèt: move repo. Fichye sit wèb yo ale nan portfolio, pa nan career-hub.

Mwen pèdi chat mwen: fichye ou yo nan GitHub. Kòmanse yon New chat, kole prompt la ankò.

Konekte nan Claude: pa gen modpas. Li voye yon kòd nan imèl ou.
