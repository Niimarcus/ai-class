Comment marche le chat du cours

1Rejoindre le cours

Sur votre ordinateur portable, ouvrez app.sparecycle.org/join et tapez le code de 6 caractères affiché à l'écran. Cliquez sur « Continuer ». Vous pouvez aussi scanner le code QR, mais le chat s'ouvre alors sur votre téléphone.

2Lisez l'écran de confidentialité

Lisez le texte de confidentialité. N'écrivez pas de noms, d'adresses, de numéros A, de détails de dossier, de numéro de sécurité sociale ni de passeport. Sparecycle n'enregistre pas ce que vous écrivez. Sur un ordinateur partagé ou de bibliothèque, cochez « Je suis sur un ordinateur partagé ou de bibliothèque ». Cliquez sur « J'ai compris. Continuer. »

3Touchez un prompt, ou écrivez

Cliquez sur « Réponses » (Answers) au-dessus de la zone de message. Choisissez la langue des réponses, par exemple Français (French) ou Kreyòl ayisyen (Haitian Creole). Touchez un bouton sous « Prompts de votre enseignant ». Le prompt va dans la case. Il n'est pas envoyé. Écrivez vos mots dans chaque partie [ ]. « Ajouter un fichier » met le texte de votre CV dans la case. Supprimez les données privées. Pour le français ou le kreyòl, utilisez la rangée d'accents pour è ò à é ç. Appuyez sur « Envoyer ».

4Lisez, écoutez, enregistrez

La réponse apparaît. Appuyez sur « Écouter » pour l'entendre. Changez la taille du texte si vous voulez. Une page web ? Cliquez sur « Enregistrer dans le projet ». Puis ouvrez « Vos fichiers » : « Aperçu » montre la page, « Télécharger » enregistre le fichier. Enregistrez votre travail sur GitHub.

5Si le chat s'arrête

Un message explique ce qui s'est passé et quoi faire. Copiez d'abord votre travail. Puis demandez à votre enseignant. Rien de ce que vous avez écrit n'est enregistré. Avant de partir : « Vos fichiers », puis « Télécharger ». Puis « Terminer le cours ».

Utilisation restante pour cette session : affichée sous la case, en pourcentage.
