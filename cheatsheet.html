Privacy rule: before you paste into AI

Remove: street address · phone · ID, visa, A-number, case numbers · date of birth · other people's names, phones, emails.

Keep: your name, city, email, jobs, schools, skills.

Public page: references say "Contact on request". No work-authorization line.

Save a new file to GitHub

  1. Open your repo on github.com.
  2. Add file → Create new file.
  3. Type the file name.
  4. Click the big box. Ctrl+V to paste.
  5. Commit changes, then Commit changes again.

Change a file: open it → pencil → Ctrl+A → Ctrl+V → Commit.
Copy it back: open it → Copy raw file (two squares).
Do not use Downloads. Shared computers delete them.

File names: exact, small letters, no spaces

career-hubPrivate. my-resume.txt resume.html story-bank.txt cover-letter-acme.txt interview-prep.txt
portfolioPublic. index.html and your photo

Photo: name it just photo. Windows adds the ending. The page tries photo.jpg, .png, .jpeg. Trap: photo.jpg.png.
Use a dash, not a space: cover-letter-acme.txt.

Messages: about 6 to 10 each Saturday

  • Answer all of Claude's questions in one message.
  • Ask for small changes, not a new page.
  • No "thank you" messages.

Limit reached? Write down the time. Do the no-AI steps. Sit with a partner. Continue later from the printed prompt.

Stuck? Top fixes

404 on live link: wait 2 min. File is index.html. Repo is Public. Settings → Pages → main → Save.

Photo missing: in portfolio repo? Named photo? Refresh with Ctrl+Shift+R.

Copy did nothing: text is selected. Press Ctrl+C (Mac: Cmd+C).

Page looks broken: first line <!DOCTYPE html>, last line </html>. Cut off? Ask for the complete file.

Nothing changes online: wrong repo. Website files go in portfolio, not career-hub.

Lost my chat: your files are in GitHub. Start a New chat, paste the prompt again.

Claude sign-in: no password. It sends a code to your email.

GitHub password: "Forgot password?" Lost 2FA phone? Use a recovery code.

More help: niimarcus.github.io/ai-class/stuck.html

Shared computer? Sign out before you leave

Save to GitHub → Log out of Claude → Sign out of GitHub → Sign out of email → Password pop-up: "Never" → Delete your Downloads → Close every window. Tip: start in a Guest or Incognito window (Ctrl+Shift+N).
