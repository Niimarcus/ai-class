No GitHub? Do the class this way.

Same lessons. Your files go to Downloads or your email, not GitHub.

Read this first. GitHub is the best place to keep your work, and a live website link needs it. If you do not have an account, this page shows what to do in each class. The class chat does not remember you, so you paste a context file at the start of every chat.

Your context file

Copy it into a text file named my-context.txt. Fill it in. Paste it into the chat at the start of every class.

MY CONTEXT FILE (paste this at the start of every chat; the class chat does not remember you)
Name: [your first name]
City: [your city]
Language I want answers in: [English / Français / Kreyòl / Español]
My target job: [job title]
The job posting (paste the full text; delete this line if none yet):
[PASTE THE JOB POSTING HERE]
My resume (paste your my-resume.txt text; no address, phone, ID, visa, A-number or case numbers):
[PASTE YOUR RESUME TEXT HERE]
My story bank (from class 3; delete this line before class 3):
[PASTE STORY BANK HERE]
My style (class 2 and after): [PICK ONE: Ink and Paper / Blueprint / Studio Pop / Velvet Night / Poster Bold]
Press Ctrl+C to copy (Mac: Cmd+C)

Remove your street address, phone, ID, visa, A-number and case numbers before you paste. Keep your name, city, jobs, schools and skills. Full privacy rule

Class 1 · Oct 28

Make my-context.txt. Do not make a repo.

  1. Skip step 3 (private repo) and step 4 (save a job posting on GitHub).
  2. Copy the context file above into a new text file (Notepad, TextEdit, or Google Docs). Fill in what you have. Save it as my-context.txt.
  3. Paste your resume text where the file says so. Paste one real job posting too.
  4. Keep the file: email it to yourself, or keep it in Downloads. On a shared computer, email it, then delete the download.

Class 2 · Oct 29

Open the file instead of GitHub.

  1. Where the class says "On GitHub, open my-resume.txt and click Copy raw file": open my-context.txt from your email or Downloads. Select the resume part. Copy it.
  2. Build resume.html as written. In the class chat, click Save to project on the page code. The file appears in your project files. Click Download next to it. The file is named resume.html.
  3. Skip "Save resume.html to GitHub". Email resume.html to yourself. To change it later, open the file in a text editor, copy all, paste it into the chat.
  4. Tailored resume: download or email it as tailored-company-name.txt.

Class 3 · Nov 4

Story bank and cover letter in files.

  1. Open my-context.txt. Copy the resume part.
  2. Prompt 2A makes your story bank. Paste the final STORY BANK into my-context.txt (the story bank line). Save the file again, and email it to yourself.
  3. Cover letter: download or email it as cover-letter-company-name.txt.

Class 4 · Nov 5

Your page as a file. A live link needs GitHub.

  1. A live website link needs GitHub. Without GitHub, you still get your portfolio as a file: index.html.
  2. In the class chat, click Save to project on your page code. Then click Download next to index.html. Double-click it to open it in your browser. Email it to yourself.
  3. Show it from your own computer or phone. Or use Print, then Save as PDF, to share it.
  4. Want a live link later? Make a GitHub account any time (setup sheet). Upload index.html to a public repo called portfolio. A helper can show you.

Class 5 · Nov 12

Photo and style, as a file.

  1. Name your photo exactly photo (Windows adds the ending). Put it in the same folder as index.html.
  2. Open index.html from that folder. Your photo shows if the names match.
  3. Do the public check from the class page on your own copy. Skip the steps that need a live link.

Class 6 · Nov 19

Practice and present from files.

  1. Interview practice needs only my-context.txt and a job posting. Paste the context file at the start of the chat.
  2. For your 3-minute talk, open index.html from Downloads or your email.
  3. Before you leave: download your files, email them to yourself, then use the sign-out checklist.
