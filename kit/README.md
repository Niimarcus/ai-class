# Class kit: portfolio page

`portfolio.css` and `portfolio.js` give every student portfolio page the same layout, from mrmakkus-cell.github.io (layout inspired by heynesh.com). Prompt 2 v3 links to them.

Student pages load these files from this address. Do not move, rename or delete them.

Styles: `blueprint`, `ink-paper`, `studio-pop`, `velvet-night`, `poster-bold` (the class on `<body>`).
