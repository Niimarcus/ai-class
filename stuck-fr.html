Page du cours Bloqué ? Aide-mémoire Déconnexion (en anglais)

Choisissez votre problème

  1. Mon lien en ligne affiche « 404 »
  2. Ma photo ne s'affiche pas
  3. Mauvais dépôt, ou mon dépôt est privé
  4. Claude dit que j'ai atteint la limite
  5. Le bouton Copy ne fait rien
  6. J'ai perdu ma conversation
  7. Ma page semble cassée après le collage
  8. J'ai oublié mon mot de passe ou le code de connexion

1Mon lien en ligne affiche « 404 »

Ce que vous voyez : Une page blanche qui dit 404: There isn't a GitHub Pages site here.

Que faire :

  1. Attendez 2 minutes. Puis actualisez la page.
  2. Vérifiez le lien : your-username.github.io/portfolio/. L'orthographe compte.
  3. Ouvrez le dépôt. Le fichier doit s'appeler exactement index.html.
  4. Pas Index.html, pas index.html.txt, pas dans un dossier.
  5. Vérifiez que le dépôt affiche Public à côté de son nom.
  6. Allez dans Settings → Pages. La branche doit être main. Cliquez sur Save.

2Ma photo ne s'affiche pas

Ce que vous voyez : Vos initiales s'affichent dans un cercle, pas votre photo.

Que faire :

  1. La photo doit être dans le dépôt portfolio, à côté de index.html.
  2. Le nom doit être photo.jpg, photo.png ou photo.jpeg. Tout en minuscules.
  3. Piège de Windows : vous avez tapé photo.jpg, mais le fichier est photo.jpg.png.
  4. Solution : renommez le fichier en photo seulement. Téléversez-le à nouveau.
  5. Une photo d'iPhone peut être en HEIC. Téléversez plutôt une capture d'écran.
  6. Attendez 1 minute. Appuyez sur Ctrl+Maj+R pour actualiser.
  7. Toujours pas de photo ? Votre index.html est peut-être ancien. Demandez à un assistant.

3Mauvais dépôt, ou mon dépôt est privé

Ce que vous voyez : Vous avez téléversé des fichiers, mais rien ne change sur votre lien en ligne.

Que faire :

  1. Regardez le nom du dépôt en haut de GitHub.
  2. career-hub est privé. Il ne fait jamais un site web. C'est voulu.
  3. Les fichiers de votre site vont dans portfolio. Il doit être Public.
  4. Pour déplacer un fichier : ouvrez-le, cliquez sur Copy raw file.
  5. Dans portfolio : Add file → Create new file. Même nom. Collez. Commit.
  6. Ne rendez jamais career-hub public. Il contient vos notes privées.

4Claude dit que j'ai atteint la limite

Ce que vous voyez : Un message comme You are out of free messages until 5:00 PM.

Que faire :

  1. Pas d'inquiétude. Votre travail est enregistré dans GitHub.
  2. Notez l'heure que Claude affiche.
  3. Faites les étapes sans IA : enregistrer, listes de contrôle, pratique.
  4. Asseyez-vous avec un partenaire. Aidez-le et regardez.
  5. Après cette heure, ouvrez un New chat. Collez à nouveau le prompt.

5Le bouton Copy ne fait rien

Ce que vous voyez : Vous cliquez sur Copy, mais le collage donne l'ancien texte ou rien.

Que faire :

  1. Vous voyez le texte jaune Press Ctrl+C to copy ? Le texte est sélectionné.
  2. Appuyez sur Ctrl+C (sur Mac : Cmd+C). Puis collez.
  3. Pas de texte jaune ? Cliquez au début, puis Maj+clic à la fin.
  4. Sur téléphone : appuyez longuement sur le texte, puis touchez Copy.

6J'ai perdu ma conversation

Ce que vous voyez : Claude affiche une conversation vide. Votre ancienne conversation a disparu de l'écran.

Que faire :

  1. Dans Claude, ouvrez le menu de gauche. Cliquez sur Chats ou Recents.
  2. Cherchez un mot de votre conversation, par exemple votre nom.
  3. Vous ne le trouvez pas ? Ce n'est pas grave. Vos fichiers sont dans GitHub.
  4. Ouvrez un New chat. Collez à nouveau le prompt avec votre texte enregistré.

7Ma page semble cassée après le collage

Ce que vous voyez : La page affiche du code en texte, est à moitié là, ou n'a pas de couleurs.

Que faire :

  1. Ouvrez le fichier sur GitHub. La première ligne doit être <!DOCTYPE html>.
  2. La dernière ligne doit être </html>.
  3. Supprimez tout texte de Claude avant la première ligne ou après la dernière.
  4. Pas de </html> à la fin ? La réponse de Claude a été coupée.
  5. Dites à Claude : « You stopped early. Give me the complete file again. » (Vous pouvez l'écrire en français : « Tu t'es arrêté trop tôt. Donne-moi le fichier complet. »)
  6. Vérifiez que le nom du fichier finit par .html, pas .txt.
  7. Cliquez dans la zone de modification. Appuyez sur Ctrl+A, puis Ctrl+V.

8J'ai oublié mon mot de passe ou le code de connexion

Ce que vous voyez : Vous ne pouvez pas vous connecter à Claude ou à GitHub.

Que faire :

  1. Claude n'a pas de mot de passe. Il vous envoie un code ou un lien par e-mail.
  2. Ouvrez d'abord votre e-mail. Ou utilisez Continue with Google.
  3. GitHub : cliquez sur Forgot password?. Ouvrez le lien dans l'e-mail. Créez un nouveau mot de passe.
  4. GitHub demande un code à 6 chiffres (2FA) ? Ouvrez l'application de codes de votre téléphone.
  5. Téléphone perdu ? Cliquez sur Use a recovery code. Tapez un code enregistré.
  6. Pas de codes de récupération ? Dites-le à un assistant. Travaillez avec un partenaire aujourd'hui.
Toujours bloqué après ces étapes ? Notez ce que vous voyez (ou prenez l'écran en photo). Montrez-le à un assistant.
